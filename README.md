# Помощник первокурсника ИВТ МИЭМ

Прототип Telegram-бота отвечает по публичным программам дисциплин **первого курса ИВТ МИЭМ НИУ ВШЭ за 2026/2027 учебный год**. Для понимания вопроса и подготовки краткого ответа используется **Agent API, `deepseek/deepseek-v4-flash`**. Ответ сопровождается нумерованными ссылками на использованные разделы программ ВШЭ.

В проект уже включён снимок **25 дисциплин с двух страниц каталога**, загруженный 14 октября 2026 года. Обычные, углублённые и индустриальные варианты хранятся раздельно. [Список дисциплин](data/SOURCES.md).

Проверки используют реальные вызовы Agent API через тот же `Assistant.ask`, что и Telegram-бот. Текст ответов в отчёте не редактировался. В отчёте явно указаны выбранная дисциплина, история диалога, источники и наблюдаемое поведение.

## Запуск

Нужен Python 3.11 или новее. После клонирования репозитория:

```bash
git clone https://github.com/stepan889/miem-freshman-assistant.git
cd miem-freshman-assistant
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
cp .env.example .env
```

В исходной рабочей папке окружение `.venv` уже создано. Далее:

1. Откройте **`.env`** в корне проекта.
2. Заполните `TELEGRAM_BOT_TOKEN` (создайте бота у [@BotFather](https://t.me/BotFather)) и `AGENTAPI_KEY` (получите ключ в [Agent API](https://agentapi.ru)).
3. В терминале этой папки выполните:

```bash
.venv/bin/python -m miem_bot check-api
.venv/bin/python -m miem_bot run
```

Откройте своего бота в Telegram и отправьте `/start`. Бот работает в личных сообщениях через long polling: отдельный домен и публичный сервер не нужны. Терминал должен оставаться запущенным. Остановка — `Ctrl+C`. Запускайте одну копию с одним Telegram-токеном.

На другом компьютере сначала создайте окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
```

Скопируйте `.env.example` в `.env`, если `.env` ещё нет, и заполните ключи. Команды рассчитаны на запуск из корня проекта. На Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.

## Настройки `.env`

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram из BotFather |
| `AGENTAPI_KEY` | API-ключ Agent API |
| `AGENTAPI_BASE_URL` | `https://api.agentapi.ru/v1/ai` |
| `AGENTAPI_MODEL` | `deepseek/deepseek-v4-flash` |
| `ALLOWED_USER_IDS` | Необязательно: ваши Telegram user ID через запятую; пустое значение открывает доступ всем |
| `MAX_CONCURRENT_REQUESTS` | Максимум одновременных вопросов, по умолчанию 3 |
| `REQUEST_COOLDOWN_SECONDS` | Минимальный интервал между вопросами одного пользователя, по умолчанию 3 секунды |

`.env` исключён из Git. При проверке ошибок ключ и тело запроса не записываются в логи. Если устанавливаете прототип для себя, можно заполнить `ALLOWED_USER_IDS`, чтобы ограничить расходы доступом выбранных пользователей.

## Как пользоваться

- `/courses` — список дисциплин с выбором конкретного варианта и кнопками «Темы», «Оценивание», «Литература».
- `/all` — сбросить выбор и историю, чтобы задать вопрос по нескольким дисциплинам.
- `/sources` — повторить ссылки последнего ответа.
- `/reset` — сбросить историю и выбранную дисциплину.
- `/help` — примеры и команды.

Можно задавать вопросы обычным текстом:

> Как считается оценка по обычной алгебре и геометрии во втором и четвёртом модулях?
>
> Какие книги рекомендуются по математическому анализу?
>
> Чем отличаются темы обычной и углублённой информатики?
>
> Как связаны обычные курсы дискретной математики и алгебры?
>
> В каких дисциплинах изучают графы?

Последние две пары сообщений сохраняются в памяти, поэтому можно продолжить: «А какую литературу рекомендуют?». Сессия очищается после часа бездействия или перезапуска. Если вариант программы неясен, модель получает инструкцию уточнить его. В режиме выбранной дисциплины вопросы ограничиваются ею; для сравнения нажмите «Все дисциплины» или отправьте `/all`.

## Как строится ответ

1. Загрузчик проходит **все страницы** [каталога с фильтром первого курса и 2026 года](https://www.hse.ru/ba/isct/courses?course=1.1.1.4&page=1&year=2026). В каждой карточке дополнительно проверяет год `2026/2027` и наличие первого курса.
2. Из публичной программы сохраняет аннотацию, цели, результаты, содержание, контроль, формулы аттестации и литературу. Коэффициенты и подписи модулей сохраняются в исходном виде. Исходные HTML при обновлении лежат в `data/raw/`; итоговый снимок — `data/courses.json`.
3. Первый запрос к Agent API определяет дисциплины, разделы и уточняет формулировку поиска с учётом сокращений и истории.
4. Локальный поиск BM25 с русским стеммингом выбирает фрагменты. Для названных дисциплин в первую очередь передаются нужные разделы; при сравнении контекст распределяется между предметами. Отдельные ключи для embeddings и векторная база не требуются.
5. Второй запрос к той же модели формирует краткий ответ по найденным фрагментам. Неопределённые вопросы могут потребовать только первого запроса.
6. Код проверяет идентификаторы источников и цитат, формирует ссылки из базы и нумерует их. Придуманные моделью URL не принимаются. Ссылки ведут на карточку и якорь раздела, например `#intermediate_certification` или `#library`.

Для кратких ответов используется `reasoning: {"effort": "none"}`. Также предусмотрен запас в бюджете: 4096 токенов для определения дисциплины и 6144 для ответа. При обрыве по лимиту запрос автоматически повторяется с увеличенным бюджетом, максимум 12288 токенов. Один некорректный JSON также допускает автоматическую повторную попытку. Повторные запросы расходуют токены Agent API.

Связь дисциплин, прямо указанная в программе, должна описываться как факт. Вывод из пересечения тем модель должна обозначать как предположение и подтверждать обеими программами. Для связи с предметом старших курсов используется только информация, опубликованная в программе предмета первого курса.

## Обновление материалов

```bash
.venv/bin/python -m miem_bot ingest
```

Загрузка работает без API-ключей. При ошибке сети, изменении структуры страниц, несовпадении курса/года или пустом каталоге предыдущий `courses.json` сохраняется. После успешного обновления **перезапустите бота**, чтобы он перечитал базу. База намеренно ограничена 2026/2027 годом и первым курсом; обновление не переключает её на другой учебный год.

## Проверка без Telegram

Локальный поиск по материалам без ключей:

```bash
.venv/bin/python -m miem_bot search "графы деревья связность"
```

Полный ответ через Agent API (нужен только `AGENTAPI_KEY`):

```bash
.venv/bin/python -m miem_bot ask "Какая литература рекомендована по математическому анализу?"
```

Проверка каталога модели и ключа (если ключ заполнен, выполняется короткий платный запрос):

```bash
.venv/bin/python -m miem_bot check-api
```

Автоматические проверки:

```bash
.venv/bin/python -m pytest -q
```

Проверяются парсинг и ограничение курса/года, обе страницы снимка, коэффициенты формул, разделы литературы, разделение вариантов, контекст сравнения, проверка цитат, HTTP-контракт Agent API, изоляция сессий и Telegram-сценарии на тестовых ответах. Реальные генерация и Telegram-поллинг требуют заполненных ключей.

## Ограничения прототипа

База содержит публичный текст карточек ВШЭ. Закрытая LMS, расписание, текущие оценки студентов и тексты самих учебников не загружаются. Бот отвечает о том, что указано в программах; подробное решение задачи, отсутствующее в программе, не имеет достаточного источника. Вопросы принимаются текстом.

Реальный прогон выявил дополнительные недостатки: лишние уточнения при уже указанном варианте, противоречивые выводы о связях дисциплин, смешение авторов программы с преподавателями и отказ валидатора цитат вместо сравнения. Заголовок карточки подтверждает выбранный год, но внутри раздела аттестации математического анализа есть также формула следующего года. Загрузчик пока не фильтрует такие отдельные записи, а модель может выйти за заявленную область. Подробные примеры и план исправлений находятся в [отчёте](deliverables/testing_30.md).

Проверка ссылок подтверждает, что источник существует в найденных материалах, но не доказывает каждое утверждение модели. Для ответственных решений сверяйте формулу с указанной программой. Если контекст большой, передаётся до 48 тысяч символов и максимум четыре выбранные дисциплины за один вопрос; уточнение вопроса помогает найти нужный фрагмент.

В Agent API передаются вопрос, последние сообщения диалога, названия дисциплин и найденные публичные фрагменты. Telegram user ID, username и токен бота в запрос к модели не добавляются. Сессии хранятся только в памяти процесса.

## Повторение демонстрационного тестирования

```bash
.venv/bin/python scripts/run_evaluation.py
.venv/bin/python scripts/run_additional_evaluation.py
.venv/bin/python scripts/run_extension_evaluation.py
.venv/bin/python scripts/build_evaluation_report.py
```

Команды выполняют платные запросы с вашим ключом Agent API. Сохраните предыдущие JSON-прогоны перед повторным запуском; полный исходный прогон не заменяет неудачные ответы повторами. После повторения модель может ответить иначе, поэтому комментарии проверки в `build_evaluation_report.py` нужно пересмотреть по новым ответам и источникам. Презентация содержит выводы именно сохранённого прогона 14 октября 2026 года.

Код распространяется по MIT. Тексты программ ВШЭ и фотография НИУ ВШЭ в презентации принадлежат соответствующим правообладателям и не включены в лицензию MIT на код. Источники программ указаны в `data/SOURCES.md`, кредит фотографии и URL находятся в заметках первого слайда.
